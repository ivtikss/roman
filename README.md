# Карамельная линия

Рекламный сайт малой автоматизированной линии для производства
леденцовой карамели с мягкой начинкой. Исходный код хранится в GitHub;
публикация исходников не означает развертывание сайта на хостинге.
Основная версия построена на Next.js, React, TypeScript, CSS
Modules, GSAP, Lenis и Three.js.

```sh
npm install
npm run dev
```

Открыть адрес, выведенный dev server. `npm run build` создает статическую
сборку в `out/`. Прежние `index.html`, `styles.css` и `script.js` сохранены
локально как резервная статическая версия, не используются Next.js и
не входят в Git-репозиторий.

## SEO и публикация

По умолчанию экспорт содержит `noindex,nofollow` и пустую карту сайта. Это
предохраняет локальную сборку от случайной индексации, если ее загрузят на
публичный хостинг. `robots.txt` разрешает сканирование: поисковик должен
увидеть HTML-тег `noindex`, если черновик всё же окажется в сети. Доступ к
черновику в таком случае нужно ограничить отдельно, так как `noindex` не
защищает содержимое.

После проверки прав на изображения, поддержки Фонда и реального домена
можно собрать индексируемый экспорт:

```sh
SITE_URL=https://example.org SITE_INDEXABLE=true npm run build
```

Заменить `example.org` на подтвержденный публичный домен. Настройка
фиксируется **во время сборки**: после любой смены домена или режима
индексации сайт надо собрать заново. Только в этом режиме появляются
canonical, абсолютные Open Graph URL, JSON-LD и адрес страницы в `sitemap.xml`.
Проверить фактические robots/canonical/sitemap и скорость на конечном
хостинге после публикации. Оптимизированное изображение первого экрана,
его фоновые продолжения, OG и favicon генерируются из локальных исходников
командой `node scripts/generate-social-assets.mjs`.
При работающем dev server `npm run visual` проверяет desktop и mobile,
3D-канвас, движение/паузу и горизонтальные переполнения; снимки остаются в
`artifacts/visual/` и не входят в сборку.

Первый экран использует переданную пользователем визуализацию всей
установки (`assets/hero-line-source.png`), показанную целиком без обрезки.
Из неё сделаны `hero-line.webp`, продолжения фоновых краёв
`hero-line-wide.webp`, `hero-line-centered.webp` и `hero-line-top.webp`,
а также OG-картинка. Исходник
сохранён отдельно, чтобы повторно получать производные файлы.
CAD-кадры показаны в инженерном разделе. Единственная
интерактивная 3D-секция реконструирует видимую компоновку в коде, а не
конвертирует исходную CAD-сборку. Два бункера ведут карамель и начинку к
соплу по отдельным трактам; оранжевые шланги в CAD обозначают подачу
сжатого воздуха, а не движение пищевой массы. Анимация показывает
движение жгута по ленте между колесами на вертикальных валах и отвод
отдельных изделий. Пауза, системное предпочтение уменьшенного движения
и выход секции из области видимости останавливают непрерывный рендер.
Студийное отражение создаётся локально в Three.js, без загрузки HDRI извне.

Шрифт Golos Text хранится локально в `public/assets/fonts/`, лицензия SIL Open Font
License 1.1 - в `public/assets/fonts/OFL.txt`. Внешние скрипты и шрифтовые CDN не нужны.

## Источники содержания

- ВКР `diplom.pdf` и предоставленные плакаты 1, 2, 4-9, 12: проектная схема,
  3D-модель, конструкция, принцип работы и учебные макеты.
- Фотографии, переданные вместе с запросом: отдельный узел подачи, конвейер и
  детали формообразующего механизма.
- Скриншоты АС «Фонд-М»: подтверждают, что этот проект относится к договору
  №1297ГССС27/108637 от 24.10.2025 и программе «Студенческий стартап». Они
  не заменяют подписанный договор и календарный план.

Изображения `cad-*.jpg` подготовлены из плаката 4; `prototype-*.jpg` - из
предоставленных фотографий. Исходные фотографии макетов перекодированы без
исходных метаданных.
`prototype-conveyor-refined.jpg` - предоставленная пользователем обработанная
версия фото макета; исходный кадр сохранен как `prototype-conveyor.jpg`.
Для первого и третьего кадров галереи использованы предоставленные пользователем
обработанные изображения `prototype-feed-studio-source.png` и
`prototype-forming-studio-source.png`. Исходные фотографии сохранены отдельно;
публичные WebP-версии создаются командой
`node scripts/generate-gallery-assets.mjs`.
`hero-line-source.png` - следующая предоставленная пользователем
визуализация всей установки, не фотография собранного оборудования.
Логотипы для локального черновика скопированы из другого сайта пользователя;
перед публикацией нужно сверить их актуальность и правила использования.

## Границы достоверности

- CAD-рендер - проектная модель, фотографии - макеты отдельных узлов. Они не
  подтверждают сборку или испытания всей линии, выпуск конфет и измеренные
  технические характеристики.
- 3D-сцена в браузере - визуализация взаимосвязи узлов, а не точная геометрия
  предоставленного файла `.a3d` и не доказательство изготовленной линии.
  Для геометрически точной интерактивной сборки нужен экспорт деталей в
  совместимый STEP/GLB из КОМПАС-3D с разрешением на веб-публикацию.
- Расчеты себестоимости, цены, производительности и окупаемости из разных
  материалов расходятся; на сайте они не используются.
- Сайт не переносит этапы и обязательства проекта №108877 из соседней папки
  `grant`. Для этого проекта требуется отдельная сверка подписанного договора
  №108637 и календарного плана.
- На исходном плакате из учебной версии КОМПАС-3D есть отметка «Не для
  коммерческого использования». Права на публичное использование
  подготовленных CAD-кадров нужно проверить до размещения сайта.
- Формулировка поддержки на странице приведена дословно по запросу
  пользователя. Ее соответствие договору №108637, состав логотипов, название
  получателя гранта и сведения для отчетности следует сверить с договором и
  текущими требованиями АС «Фонд-М».
- Индексируемую сборку нельзя публиковать до сверки документации и
  получения прав на фотографии и CAD-кадры; для коммерческого обращения
  также потребуются проверенные контакты.

Проект намеренно не содержит скриншотов личного кабинета, персональных данных,
банковских реквизитов, показателей без протоколов или фиктивных контактов.
